# Бараа Толь

**Худалдаж авахаасаа өмнө шалга.** Бусад хэрэглэгчдийн бодит туршлагаас барааны чанар,
эдэлгээ, юу нь ихэвчлэн эвдэрдэг, аль нь илүү дээр болохыг харуулдаг платформ.

Мэдээлэлтэй хэрэглэгч чанаргүй бараа авахаа болино. Амархан эвдэрдэг бараа зарагдахгүй бол
худалдагч дахин захиалахаа больж, үйлдвэрлэгч чанартай бараа хийхийг зорино. Үр дүнд нь
шударга өрсөлдөөн бий болж, хог хаягдал багасна.

## Барааг хэрхэн таньдаг вэ?

1. **Баркод** байвал хамгийн түрүүнд түүгээр хайна. Баркод таарвал 100% ижил бараа гэсэн үг.
2. **Олон өнцгийн видео скан.** Бараа бүртгэхдээ хэрэглэгч барааг тал бүрээс нь бичнэ.
   Сервер видеоноос **тод, гэрэл зөв, бие биенээсээ өөр өнцгийн** 16 хүртэлх кадрыг
   автоматаар сонгож, кадр бүрийн "хээ"-г хадгална.
3. **Зургаар хайх.** Хайж байгаа хүн ганц зураг авахад хангалттай. Хадгалсан олон өнцгийн
   аль нэгтэй таарвал бараа олдоно.

3D загвар бүтээх шаардлагагүй: 2D зургийг олон өнцгийн 2D зурагтай харьцуулах нь илүү
хурдан бөгөөд найдвартай.

## Дараагийн хувилбарууд

- Flutter апп
- DINOv2 загвараар бодит зургууд дээр таних чадварыг тохируулах
- Хэрэглэгчийн бүртгэл, худалдан авалтаа баталгаажуулсан сэтгэгдэл, хуурамч сэтгэгдэл илрүүлэх
- Шошгон дээрх брэнд, моделийн бичгийг таних (OCR)
- **v2: Гомдол барагдуулах туслах.** Хуулийн заалт, гомдлын бичгийн загвар, хаана хандах
- PostgreSQL + pgvector
