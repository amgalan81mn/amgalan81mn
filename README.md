# Унаа — замдаа хүн авах апп

Нэг чиглэлд яваа жолооч зам дээр зогсож буй хүнийг авч дөхүүлэх апп. Такси ч биш, автобус ч биш.

## Одоо байгаа зүйл

`backend/` — Python (FastAPI) сервер, PostgreSQL өгөгдлийн сан.

- **Бүртгэл:** утасны дугаараар SMS кодоор нэвтрэх, овог нэр, регистр, үнэмлэх болон нүүр зураг.
- **Жолооч, машин:** жолооны үнэмлэх, банкны данс, улсын дугаар, марк, өнгө, суудлын тоо, машины 4 зураг, гэрчилгээ.
- **Админы шалгалт:** хувийн бүртгэл, жолооч, машин тус бүрийг зөвшөөрөх эсвэл шалтгаантай татгалзах, хэрэглэгч хаах.
- **Зураг хадгалалт:** шифрлэгдэж хадгалагдана, зөвхөн эзэн болон админ үзнэ, админы үзсэн бүр бүртгэгдэнэ.
- **Хэтэвч:** цэнэглэх, дүн түгжих, аялал дуусахад шимтгэл суутгаж жолоочид шилжүүлэх, үлдсэнийг буцаах, банк руу татах.
- **Үнийн тооцоо:** үндсэн тариф, лааны голын хүрээ, хүн нэмэгдэхэд буурах үнэ, дутуу хүргэсэн үеийн тооцоо, шатлалтай шимтгэл.
- **Замдаа хүн авах:** жолооч маршрутаа зарлаж байршлаа илгээнэ. Зорчигч «авна» үнээ тавихад мөнгө түгжигдэнэ. Жолоочид зөвхөн маршрутынхаа урд, ойролцоо, үнэ таарсан хүмүүс өндөр үнээр эрэмбэлэгдэж харагдана.
- **Дуугаар олох:** жолооч «авна» дарахад хоёр утсанд ижил `tune` дугаар очно. Ойролцоо уулзаж буй хосууд өөр өөр дугаартай байна.
- **Аялал:** «Суулаа», «Буулаа», жолооч тоо нэмэх (гэр бүл, найзууд), цуцлалт, маршрут дуусгах. Хамт явсан хүмүүсээр үнэ буурч, буухад шимтгэл суутгаж тооцоо хийгдэнэ.
- **Аян (олон машинаар):** нийт төсөв нэг удаа түгжигдэнэ. Машин бүр зорчигчийг хэр ойртуулснаар төлбөр авна. «Буулаа» дармагц тооцоо хийгдэж, ижил очих газар руу шинэ хүсэлт автоматаар үүснэ. Явган алхахад суух цэг хамт шилжинэ. Түгжрэлийг (машин 1 минут бараг хөдлөөгүй) илрүүлж, урдах таарах жолооч нарын тоог харуулна. Буусны дараа хоёр утас хамт хөдөлсөөр байвал «сэжигтэй» гэж тэмдэглэж, эрт буусны доод төлбөрийг суутгана.
- **Зах зээл:** хэлцлүүдээс лааны график (`/market/candles`), зорчигчид санал болгох үнэ (`/rides/quote`).

Тариф, шимтгэл, хязгаарын бүх тоо `backend/app/config.py`-д байгаа жишээ утга. `.env` файлаар солино.

## Хараахан хийгээгүй

- Flutter апп
- Бодит цагийн холболт (WebSocket): одоо апп хэдэн секунд тутам асууна
- Ирээгүй зорчигчийн торгууль, яаралтай товч, аялал хуваалцах холбоос
- Жинхэнэ SMS, төлбөрийн систем, Google Maps (одоо туршилтын горим)
- Bluetooth-ээр интернетгүй ажиллах горим (2-р шат; хэтэвчний `offline_reserve` төрөл үүнд бэлдсэн)

## Ажиллуулах

Docker-той бол:

```
docker compose up --build
```

Сервер `http://localhost:8000` дээр асна. `http://localhost:8000/docs` хаягаар бүх API-г хөтчөөс туршина.

Docker-гүй бол PostgreSQL 16 суулгаж `unaa` нэртэй хэрэглэгч, өгөгдлийн сан үүсгээд:

```
cd backend
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env
alembic upgrade head
uvicorn app.main:app --reload
```

Эхний админыг үүсгэх (эхлээд тэр дугаараар нэвтэрсэн байх ёстой):

```
python -m app.cli make-admin 99112233
```

## Тест

`unaa_test` нэртэй өгөгдлийн сан хэрэгтэй.

```
cd backend
pytest
```

## Туршилтын горимын анхааруулга

`UNAA_SMS_MODE=dev` үед SMS код API-ийн хариунд шууд буцна, `UNAA_PAYMENTS_MODE=dev` үед хэн ч хэтэвчээ үнэгүй цэнэглэж чадна. Жинхэнэ хэрэглэгчид нээхээс өмнө хоёуланг нь `provider` болгож, `UNAA_JWT_SECRET`, `UNAA_FILE_ENCRYPTION_KEY`-г заавал солино.
