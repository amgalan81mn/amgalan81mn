# Бараа Толь

**Худалдаж авахаасаа өмнө шалга.** Бусад хэрэглэгчдийн бодит туршлагаас барааны чанар,
эдэлгээ, юу нь ихэвчлэн эвдэрдэг, аль нь илүү дээр болохыг харуулдаг платформ.

## Зорилго

Мэдээлэлтэй хэрэглэгч чанаргүй бараа авахаа болино. Амархан эвдэрдэг бараа зарагдахгүй бол
худалдагч дахин захиалахаа больж, үйлдвэрлэгч чанартай бараа хийхийг зорино. Үр дүнд нь
шударга өрсөлдөөн бий болж, хог хаягдал багасна.

## Одоо байгаа боломжууд (v0.1)

- **Зургаар хайх.** Барааны зургийг оруулахад санд байгаа ижил болон төстэй барааг олно.
  Зургийн "хээ"-г хэрэглэгчийн хөтөч дээр тооцоолно:
  - MobileNet (TensorFlow.js): өөр өнцгөөс авсан ижил барааг ч таньдаг. `cdn.jsdelivr.net`-ээс ачаалагдана.
  - Энгийн хээ (арын дэвсгэрийг хассан өнгө + дүрс): интернэт/CDN байхгүй үед ажиллана, гэхдээ бүдүүлэг.
- **Нэрээр хайх, ангиллаар шүүх, эрэмбэлэх.** Эрэмбэлэх сонголтууд: нийт оноо, үнэ цэнэ, хамгийн их эвдэрдэг.
- **Барааны хуудас.** Үүнд:
  - 0–100 оноо, ангилал доторх байр
  - Эвдэрсэн хувь, эвдрэх хүртэлх хугацааны медиан, "дахин авна" гэсэн хувь
  - **Юу нь ихэвчлэн эвдэрдэг вэ?** гэсэн график
  - Эвдрэлийн хувь өндөр бол анхааруулга
  - "Хэрэглэгчид оронд нь санал болгосон" болон "илүү өндөр үнэлгээтэй" бараанууд
- **Туршлага бичих.** Од, эвдэрсэн эсэх, юу нь эвдэрсэн, хэдэн сард эвдэрсэн, хэдээр авсан,
  дахин авах эсэх, давуу ба сул тал, мөн "илүү дээр байсан бараа"-г бичнэ.

### Оноо хэрхэн бодогддог вэ?

`оноо = 50% × сэтгэл ханамж + 50% × эвдрэхгүй байх магадлал`

Цөөн сэтгэгдэлтэй бараа азаар дээгүүр гарахгүйн тулд Байесын дундажийг ашигладаг. Сэтгэгдэлгүй
бараанд оноо өгөхгүй. **Үнэ цэнэ** нь тухайн ангиллын дундаж үнэтэй харьцуулсан оноо юм.
Дэлгэрэнгүйг `server/scoring.js`-ээс харна уу.

## Ажиллуулах

Node.js 22.13 буюу түүнээс дээш хувилбар шаардлагатай. Суурилагдсан SQLite-г ашигладаг тул өөр өгөгдлийн сан суулгах хэрэггүй.

```bash
npm install
```

```bash
npm run seed   # заавал биш: үзүүлэнд зориулсан ЗОХИОМОЛ жишээ өгөгдөл
```

```bash
npm start      # http://localhost:3000
```

```bash
npm test
```

Тохиргоо: `PORT` (өгөгдмөл нь 3000), `DATA_DIR` (өгөгдмөл нь `./data`; энд өгөгдлийн сан болон зургууд хадгалагдана).

## Бүтэц

```
server/index.js     REST API (Express)
server/db.js        SQLite схем
server/scoring.js   Оноо, эвдрэлийн статистик, зургийн төстэй байдал
public/             Хэрэглэгчийн интерфейс (энгийн JS, бүтээх алхам шаардлагагүй)
public/imagefeatures.js  Хөтөч дээр зургийн хээ тооцоолох
scripts/seed.js     Жишээ өгөгдөл
test/               Тестүүд
```

## Дараагийн хувилбарууд

- **v2: Гомдол барагдуулах туслах.** Хэрэглэгчийн эрхийн тухай хуулийн холбогдох заалт,
  гомдлын албан бичгийн загвар, хаана хандах (худалдагч → ШӨХТГ → шүүх), гомдлын явцыг хянах.
- Худалдан авалтаа баталгаажуулсан сэтгэгдэл (баримтын зураг)
- Хуурамч сэтгэгдэл, худалдагчийн өөрийгөө магтсан сэтгэгдлийг илрүүлэх (бүртгэл, давтамжийн хязгаар)
- Дэлгүүр, худалдагчийн үнэлгээ: аль дэлгүүр муу бараа их зардаг вэ
- Ижил барааг нэгтгэх (давхардсан бүртгэл)
- Зургийн хээг сервер дээр тооцоолох, вектор хайлтын индекс
