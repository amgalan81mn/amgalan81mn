# Сургалтын жор — загварыг эхнээс нь дахин сургах дараалал

> Энэ файлыг TTS төслийнхөө үндсэн хавтсанд хуулна. Алхам бүрийг дуусгаад энд бичиж,
> `tools/checkpoint.sh save "..."` хийнэ. Диск эвдэрсэн ч энэ жороор загвараа дахин сургана.

## 0. Орчин

Сангуудын яг хувилбар `.checkpoint/requirements.lock`-д, Python, GPU, CUDA-ийн мэдээлэл
`.checkpoint/environment.txt`-д алхам бүрт автоматаар бичигдэнэ. Дахин суулгах:

```bash
python -m venv .venv
```

```bash
.venv/Scripts/pip install -r .checkpoint/requirements.lock
```

## 1. Өгөгдөл

| Өгөгдөл | Эх сурвалж (хаанаас авах) | Нөөц хаана | Тоо / хэмжээ |
|---|---|---|---|
| Жишээ: Монгол дуу хоолойны бичлэг | Өөрөө бичсэн | Google Drive: `TTS/raw_audio.zip` | 12 цаг, 8 400 файл |

Файл бүрийн sha256 `.checkpoint/large-files.tsv`-д бий. Сэргээсний дараа
`tools/checkpoint.sh verify` ажиллуулбал яг тэр өгөгдөл мөн эсэхийг баталгаажуулна.

## 2. Сургах дараалал

Алхам бүрт: ажиллуулсан **команд**, **тохиргооны файл**, **seed**, үр дүн.

| Алхам | Команд | Тохиргоо | Seed | Үр дүн / тэмдэглэл | Checkpoint |
|---|---|---|---|---|---|
| 1. Өгөгдөл цэвэрлэх | `python scripts/prepare.py` | `configs/prepare.yaml` | — | 8 120 файл үлдэв | step-003 |
| 2. Текст → дуудлага | `python scripts/phonemize.py` | `configs/phon.yaml` | — | | step-004 |
| 3. Үндсэн сургалт | `python train.py -c configs/base.yaml` | `configs/base.yaml` | 1234 | 200k алхам, loss 0.31 | step-007 |
| 4. Нарийвчлан тохируулах | `python train.py -c configs/ft.yaml --resume ...` | `configs/ft.yaml` | 1234 | | step-009 |

## 3. Дахин сургахад анхаарах

- Seed-ийг тохиргоонд заавал бичнэ. Ингэснээр үр дүн аль болох давтагдана (GPU дээр 100% ижил биш ч ойролцоо гарна).
- Тохиргоог командын мөрөнд биш, `configs/*.yaml` файлд бичвэл GitHub-д хадгалагдана.
- Сургалт олон хоног үргэлжилдэг бол хамгийн сайн загварын жинг Drive-д нөөцөлбөл цаг хэмнэнэ. Гэхдээ энэ заавал биш: жор, өгөгдөл байвал дахин сургаж болно.
