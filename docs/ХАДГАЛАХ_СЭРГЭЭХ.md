**Гол санаа:** эх кодын жинхэнэ хувь нь **GitHub** дээр байна. Компьютер бол зүгээр л
ажлын хуулбар. Хатуу диск эвдэрсэн ч GitHub-аас бүгдийг 5 минутад буцааж татна.

```
 Компьютер (ажлын хуулбар)  ── git push ──►  GitHub (жинхэнэ хувь)  ◄── Claude Code (cloud)
          ▲                                        │
          └──────────── git clone / pull ──────────┘
```

## 3. Шинэ компьютер дээр сэргээх (алхам алхмаар)

**3.1.** Git суулгана: <https://git-scm.com/downloads>



## 4. Өдөр тутмын дадал — алдагдахгүй байх

Компьютер дээр өөрчлөлт хийх бүрт ажлын төгсгөлд:

```bash
git add -A
```

```bash
git commit -m "Юу хийснээ товч бичнэ"
```

```bash
git push
```

Ажил эхлэхдээ GitHub дээрх хамгийн сүүлийн хувилбарыг татна (Claude cloud дээр хийсэн өөрчлөлт ч ирнэ):

```bash
git pull
```

**Claude Code (claude.ai/code) дээр ажиллахад:** Claude ажлаа commit хийж GitHub руу push хийдэг.
Сесс дуусахад "push хийсэн үү?" гэж асуугаад, github.com дээр commit харагдаж байгааг шалгаарай.
Push хийгдээгүй ажил cloud контейнер устахад алга болно.

**Шалгах:** `github.com/amgalan81mn/amgalan81mn` → Branch сонгох → "commits" дээр сүүлийн
өөрчлөлт харагдаж байвал аюулгүй.

  дараа серверийн өгөгдлийн санг өдөр бүр автоматаар нөөцлөнө (PostgreSQL `pg_dump` → үүлэн сан).
- **Том файл (видео, дизайн):** Google Drive.

## 7. Олон файлтай төсөл (TTS г.м.): алхам бүрийг хадгалж, алдвал сэргээх

Кодын файл, тохиргоо, скриптийг GitHub-д алхам бүрээр хадгална. Загварын жин, аудио,
датасет мэтийн том файлыг GitHub-д оруулахгүй. Харин тэдгээрийн **жагсаалт, хэмжээ, sha256**-ийг
алхам бүрт бичиж үлдээнэ. Ингэснээр алдсан үед юуг нь буцааж хуулахаа яг мэдэнэ.

**Нэг удаа тохируулах** (D диск дээрх төслийн хавтсанд, Windows бол Git Bash-аар):

```bash
cd /d/TTS
```

```bash
git init
```

Энэ repo-гийн `templates/tts.gitignore`-ийг төслийнхөө хавтсанд `.gitignore` нэрээр,
`tools/checkpoint.sh`-ийг `tools/` хавтсанд хуулна. github.com дээр **private** repo үүсгээд холбоно:

```bash
git remote add origin https://github.com/amgalan81mn/tts.git
```

**Алхам бүрийн төгсгөлд:**

```bash
tools/checkpoint.sh save "Өгөгдөл цэвэрлэх скрипт дуусав"
```

Энэ команд `step-001`, `step-002` гэх мэт дугаартай алхам үүсгээд GitHub руу илгээнэ.
50MB-аас том файл орох гэвэл зогсоож анхааруулна.

**Алдсан, эвдэрсэн үед:**

| Хэрэгцээ | Команд |
|---|---|
| Ямар алхмууд байгааг харах | `tools/checkpoint.sh list` |
| Нэг алхамд юу өөрчлөгдсөнийг харах | `tools/checkpoint.sh show step-007` |
| Эвдэрсэн нэг файлыг сэргээх | `tools/checkpoint.sh restore step-007 src/model.py` |
| Бүх төслийг тэр алхмаар сэргээх (хуучин ажил устахгүй, шинэ branch) | `tools/checkpoint.sh restore step-007` |
| Том файлууд (жин, аудио) бүрэн эсэхийг шалгах | `tools/checkpoint.sh verify` |

Хатуу диск бүрэн алдагдвал `git clone`-оор кодоо татаад, `verify`-ийн жагсаасан том файлуудыг
Google Drive эсвэл Hugging Face Hub (private) нөөцөөсөө буцааж хуулна.

### Сургалтын дарааллыг хадгалах

Эх код, тохиргоо, сургах дараалал хадгалагдсан бол загварын жинг алдсан ч **эхнээс нь дахин
сургаж** болно. Үүний тулд `save` алхам бүрт дараахыг автоматаар бичнэ:

- `.checkpoint/requirements.lock`: сангуудын яг хувилбар (`pip freeze`)
- `.checkpoint/environment.txt`: Python, GPU, CUDA-ийн хувилбар
- `.checkpoint/large-files.tsv`: өгөгдлийн файл бүрийн sha256 (яг ямар өгөгдөл дээр сургасан)

Сургах дарааллаа `templates/tts/СУРГАЛТ.md` загварын дагуу бичнэ.
⚠️ **Эх өгөгдлийг (бичлэг, текст) өөр газар заавал нөөцөлнө.** Код өгөгдөлгүйгээр загвар сургаж чадахгүй.
Нийтэд нээлттэй датасет бол хаанаас татахыг нь жорд бичихэд хангалттай.
