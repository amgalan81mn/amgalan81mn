# Төслөө алдахгүй хадгалах, шинэ компьютер дээр сэргээх заавар

**Гол санаа:** эх кодын жинхэнэ хувь нь **GitHub** дээр байна. Компьютер бол зүгээр л
ажлын хуулбар. Хатуу диск эвдэрсэн ч GitHub-аас бүгдийг 5 минутад буцааж татна.

```
 Компьютер (ажлын хуулбар)  ── git push ──►  GitHub (жинхэнэ хувь)  ◄── Claude Code (cloud)
          ▲                                        │
          └──────────── git clone / pull ──────────┘
```

## 1. Юу хаана хадгалагддаг вэ

| Зүйл | Хаана | Алдвал яах вэ |
|---|---|---|
| Эх код, README, баримт бичиг, тест | GitHub: `github.com/amgalan81mn/amgalan81mn` | `git clone`-оор буцааж татна |
| Ажлын түүх (хэн, хэзээ, юу өөрчилсөн) | GitHub (commit бүр) | Кодтой хамт ирнэ |
| Claude-тай хийсэн яриа | claude.ai/code → сессийн жагсаалт | Яриа хадгалагдана, гэхдээ **кодын эх сурвалж бол GitHub** |
| Claude-д зориулсан төслийн товч | Repo дахь `CLAUDE.md` | Шинэ сесс автоматаар уншаад үргэлжлүүлнэ |
| `.venv/`, `node_modules/` | Зөвхөн компьютер | Хадгалах шаардлагагүй: `pip install`, `npm install`-оор дахин үүснэ |
| `data/` (өгөгдлийн сан, хэрэглэгчийн зураг) | Зөвхөн компьютер/сервер | ⚠️ GitHub-д **оруулахгүй**. Доорх 5-р хэсгийг үз |
| `.env`, нууц үг, API түлхүүр | Зөвхөн компьютер | ⚠️ GitHub-д **хэзээ ч оруулахгүй**. Нууц үгийн менежерт хадгална |

## 3. Шинэ компьютер дээр сэргээх (алхам алхмаар)

**3.1.** Git суулгана: <https://git-scm.com/downloads>
(Команд мөр хэрэглэхгүй бол **GitHub Desktop**: <https://desktop.github.com> — товч дараад clone хийнэ.)

**3.2.** Төслөө татна:

```bash
git clone https://github.com/amgalan81mn/amgalan81mn.git
```

```bash
cd amgalan81mn
```

**3.3.** Хэрэгтэй төслийнхөө branch руу шилжинэ:

```bash
git checkout claude/wizardly-gauss-9mxhof
```

**3.4.** Ажиллуулна (Бараа Толь):

```bash
cd backend
```

```bash
python -m venv .venv
```

```bash
source .venv/bin/activate
```

(Windows дээр: `.venv\Scripts\activate`)

```bash
pip install -r requirements-dev.txt
```

```bash
uvicorn app.main:app --reload
```

**3.5.** `.env` болон `data/`-г нөөцөөсөө буцааж хуулна (байгаа бол).

## 4. Өдөр тутмын дадал — алдагдахгүй байх

Компьютер дээр өөрчлөлт хийх бүрт ажлын төгсгөлд:

```bash
git add -A
```

```bash
git commit -m "Юу хийснээ товч бичнэ"
```

```bash
git push
```

Ажил эхлэхдээ GitHub дээрх хамгийн сүүлийн хувилбарыг татна (Claude cloud дээр хийсэн өөрчлөлт ч ирнэ):

```bash
git pull
```

**Claude Code (claude.ai/code) дээр ажиллахад:** Claude ажлаа commit хийж GitHub руу push хийдэг.
Сесс дуусахад "push хийсэн үү?" гэж асуугаад, github.com дээр commit харагдаж байгааг шалгаарай.
Push хийгдээгүй ажил cloud контейнер устахад алга болно.

**Шалгах:** `github.com/amgalan81mn/amgalan81mn` → Branch сонгох → "commits" дээр сүүлийн
өөрчлөлт харагдаж байвал аюулгүй.

## 5. Git-д ордоггүй зүйлсийн нөөц

- **`.env`, нууц үг:** Bitwarden, 1Password зэрэг нууц үгийн менежерт.
- **`data/` хавтас:** одоогоор туршилтын өгөгдөл тул заавал биш. Бодит хэрэглэгчтэй болсны
  дараа серверийн өгөгдлийн санг өдөр бүр автоматаар нөөцлөнө (PostgreSQL `pg_dump` → үүлэн сан).
- **Том файл (видео, дизайн):** Google Drive.

## 6. Нэмэлт хамгаалалт

- GitHub бүртгэлдээ **2 шаттай баталгаажуулалт (2FA)** асаана: Settings → Password and authentication.
- Recovery code-оо цаасан дээр бичиж хадгална. Утсаа алдвал үүгээр нэвтэрнэ.
- Repo-гоо **private** байлгавал зөвхөн та харна.
