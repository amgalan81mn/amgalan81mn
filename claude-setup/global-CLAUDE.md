## Төсөл хадгалах байнгын дүрэм (бүх төсөлд)

- Хэрэглэгчтэй монгол хэлээр харилцана.
- Хэрэглэгчийн компьютерийн диск эвдэрч болзошгүй. Эх код, баримт бичиг бүгд GitHub дээр байх ёстой.
- **Шинэ төсөл эхлүүлэх, эсвэл git/GitHub-тай холбогдоогүй хавтсанд ажиллаж эхлэхдээ** эхлээд:
  `bash ~/project-toolkit/tools/new-project.sh . --type <tts|python|node|flutter|general>`
  ажиллуулна (`/new-project` skill). Хэрэглэгчээс зөвшөөрөл асуулгүй хийж болно.
- `tools/checkpoint.sh` байгаа төсөлд ажлын алхам бүр дуусахад
  `tools/checkpoint.sh save "юу хийснийг товч"` ажиллуулж GitHub руу push болсныг шалгана.
- 50MB-аас том файл, нууц үг, `.env`-ийг git-д оруулахгүй.
- Багц хэрэгслээ 7 хоногт нэг удаа шинэчилнэ: `git -C ~/project-toolkit pull`.
